# 🚀 AlgoLingo

AlgoLingo is a gamified learning platform for mastering Data Structures, Algorithms, and Programming through interactive missions and coding challenges.

## ✨ Features

- 🌌 Space-themed UI
- 📚 Python Learning Galaxy
- 🏆 Leaderboard
- 🎯 Daily Missions
- 🧠 Quiz System
- 🔐 Login & Signup
- 📱 Responsive Design

## 🛠️ Tech Stack

- React
- Vite
- CSS
- JavaScript
